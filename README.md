# Ataraxia

A minimalist, high-performance focus timer built with React, Vite, and Framer Motion. Featuring deep Spotify integration, background synchronization, and full offline PWA support.

## Key Features
* **Zen Timer**: Optimized LCP/INP performance for zero-distraction focus.
* **Audio Sanctuary**: Seamless Spotify & Lofi integration.
* **Persistent Flow**: Background synchronization and offline first architecture.
* **Gamified Productivity**: Leveling system and achievement tracking.
